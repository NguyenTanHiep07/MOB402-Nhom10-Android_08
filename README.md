# GoDrop - Ứng dụng Giao Hàng

Đây là thư mục gốc của dự án GoDrop (Nhóm 10).
Dự án bao gồm hai phần chính:
1. **Code (Android App):** Ứng dụng di động viết bằng Kotlin và Jetpack Compose.
2. **Backend (Server):** Ứng dụng Spring Boot cung cấp REST API.

## Hướng dẫn kỹ thuật chi tiết
Toàn bộ tài liệu kỹ thuật chi tiết về cấu trúc DB, API contract, và hướng dẫn hệ thống đã được gộp chung lại. Bạn có thể xem tại:
👉 [DOCX/GoDrop-Huong-Dan-Ky-Thuat.md](DOCX/GoDrop-Huong-Dan-Ky-Thuat.md)

## Cách chạy dự án
- Để chạy Backend, xem [Backend/README.md](Backend/README.md).
- Để chạy Android App, mở thư mục `Code` bằng Android Studio và chạy trên thiết bị (API >= 26).
