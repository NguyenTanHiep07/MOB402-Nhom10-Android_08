# GoDrop Delivery Backend

Dự án ứng dụng giao hàng đa nền tảng gồm Android (Kotlin) và Backend (Spring Boot, MongoDB).

## Tài liệu kỹ thuật
Vui lòng xem file [GoDrop-Huong-Dan-Ky-Thuat.docx](DOCX/GoDrop-Huong-Dan-Ky-Thuat.docx) để biết đầy đủ chi tiết về kiến trúc, database, luồng nghiệp vụ và cách cấu hình toàn bộ hệ thống.

## Yêu cầu môi trường
- Java 21
- MongoDB (Atlas hoặc Local)

## Chạy dự án Backend
Khởi động server:
```bash
cd Backend
./gradlew bootRun
```
