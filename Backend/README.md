# GoDrop Backend

Đây là mã nguồn Backend của dự án GoDrop, được xây dựng bằng Spring Boot (Java 21) và MongoDB.

## Cài đặt và chạy

1. Cài đặt **Java 21** và đảm bảo **MongoDB** đang chạy ở `localhost:27017`.
2. Mở terminal tại thư mục `Backend` và chạy lệnh sau:
   ```bash
   ./gradlew bootRun
   ```
3. Server sẽ chạy tại `http://localhost:8080`.
